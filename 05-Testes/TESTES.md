# Estratégia de Testes

Prioridades:

1. regras de negócio e integridade referencial;
2. autenticação e permissões;
3. validação de entradas e uploads;
4. contratos da API;
5. compilação e comportamento da interface.

A Sprint 1 possui testes de integração da API Django para o módulo de
Propriedades. O frontend é validado por TypeScript estrito e build Vite. Testes
automatizados de componentes devem ser introduzidos quando a infraestrutura de
testes do frontend for definida.

Os comandos oficiais estão em `tests/README.md`.
