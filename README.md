# AGRO-AI-PRO

Projeto em fase inicial para construção de um ERP agrícola profissional.

## Objetivo da Sprint 1
Estabelecer uma base técnica sólida para backend Django, frontend React, infraestrutura Docker e documentação inicial.

## Estrutura do repositório
- backend/: aplicação Django
- frontend/: aplicação React + TypeScript
- docker/: arquivos de containerização
- docs/: documentação técnica
- database/: persistência de dados
- backups/: backups e exportações

## Próximos passos
- Consolidar backend Django 5 com DRF
- Preparar frontend com Vite + Material UI
- Definir ambiente Docker Compose com PostgreSQL, Redis e Nginx
