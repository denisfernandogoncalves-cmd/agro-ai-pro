# Roadmap do AGRO-AI-PRO

## Sprint 1 - Base profissional

- Organizar estrutura do repositório
- Consolidar backend Django 5
- Preparar frontend React 19 + Vite + TypeScript
- Definir infraestrutura com Docker, Redis e Nginx
- Documentar arquitetura e processo de contribuição

## Sprints da versão 1.0

- [x] infraestrutura, propriedades, talhões e geoprocessamento;
- [x] previsão climática por propriedade;
- [x] mercado e clima no Corn Belt;
- [x] financeiro;
- [x] estoque e insumos;
- [x] operações;

- [x] relatórios e dashboards;
- [x] inteligência artificial e automação;
- [x] aplicativo.
