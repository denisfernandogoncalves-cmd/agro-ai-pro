# Guia de contribuição

## Padrões básicos
- Manter a estrutura de pastas organizada
- Evitar implementação de regras de negócio na Sprint 1
- Trabalhar com pequenas alterações e revisão contínua
- Manter documentação atualizada

## Fluxo recomendado
1. Criar branch para a tarefa
2. Implementar em pequenas etapas
3. Validar localmente com Docker Compose
4. Documentar mudanças relevantes
